# Getting Started

Welcome to the Kist documentation! This guide will help you get started with our tools and libraries.

## What is Kist?

Kist is a collection of modern, open-source development tools and libraries created by [Scape Agency](https://www.scape.agency). Our projects are designed to help developers build better software faster.

## Quick Start

Browse our [projects](/projects/) to find the tools that fit your needs. Each project has its own detailed documentation with installation instructions and usage examples.

## Installation

Most Kist projects can be installed via npm:

```bash
npm install @getkist/[project-name]
```

Or using yarn:

```bash
yarn add @getkist/[project-name]
```
